# 💡 ESP8266 Wireless Light Control

An ESP8266-based wireless light control project using a relay module.

## 📌 Project Overview

This project demonstrates how an ESP8266 microcontroller can be used to control an electrical load wirelessly through a relay module.

The ESP8266 receives a control command and switches the relay ON or OFF.

## 🧰 Hardware Components

- ESP8266 Development Board
- 1-Channel Relay Module
- LED / Low-voltage DC Load
- Jumper Wires
- USB Cable
- Power Supply

## 💻 Software & Tools

- Arduino IDE
- Arduino C/C++
- ESP8266 Board Package

## ⚙️ Working

1. The ESP8266 is connected to the relay module.
2. The ESP8266 receives a wireless control command.
3. The relay switches according to the received command.
4. The connected load can be turned ON or OFF remotely.

## 🔌 Basic Pin Connection

| Component | ESP8266 |
|---|---|
| Relay IN | D1 |
| Relay VCC | 5V / Suitable supply |
| Relay GND | GND |

> Pin configuration may vary depending on the ESP8266 board and relay module used.
